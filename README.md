The website does NOT store 50 video IDs. You manage the songs in your YouTube playlist, and the website loads that playlist.

## How it works

Visitor opens website
-> presses Play
-> embedded YouTube player loads the playlist
-> songs play inside the website
-> Next/Previous works
-> you can update the YouTube playlist without changing the website code

## Important

The browser may block autoplay until the visitor interacts with the page. This is normal browser behavior.

The site does not download or host the music files. Playback is through YouTube's embedded player and is subject to YouTube's player behavior, rights restrictions, and availability.

For the website to remain usable, keep the playlist public or otherwise embeddable and make sure the videos permit embedding.
